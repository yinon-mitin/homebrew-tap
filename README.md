# yinon-mitin/tap

Homebrew casks for [yinon-mitin](https://github.com/yinon-mitin)'s macOS apps.

| Cask | App |
|------|-----|
| `quickpeek` | [QuickPeek](https://github.com/yinon-mitin/QuickPeek) — Quick Look previews and file details for the files macOS leaves blank |

```sh
brew install --cask yinon-mitin/tap/quickpeek
```

The casks are updated automatically when a new release is published.
